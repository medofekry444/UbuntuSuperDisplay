# Android prototype download

[Download UbuntuSuperDisplay-debug.apk](https://github.com/medofekry444/UbuntuSuperDisplay/raw/refs/heads/main/downloads/UbuntuSuperDisplay-debug.apk)

This debug APK is version 0.2.0, built from source commit
`20e3298ac191c683fb42fbdcf4308a0352583cd8`. It requires Android 8.0 or newer.
APK signature verification passed. Its checksum is recorded in `SHA256SUMS`.

Download the file on your tablet, open it, and allow installation from your
browser/file manager when Android asks. Follow the [streaming guide](../docs/streaming.md)
to start the laptop server and connect the tablet.

This is a development build. Actual HONOR Pad playback remains a hardware test.
APK files are temporarily distributed here because release uploads are unavailable
from the development environment; generated build directories remain ignored.
